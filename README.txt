README.txt

Ce portfolio présente mes compétences en développement web, incluant des sections sur mes projets, expériences professionnelles, ainsi que mes coordonnées pour un contact direct. Il a été conçu en utilisant HTML, CSS et JavaScript pour offrir une expérience interactive et fluide.

Contenu des pages
-------
Accueil (index.html) : Page principale du portfolio avec une vue d'ensemble de mes compétences et projets.
À propos (about.html) : Présentation de mon parcours, de mes objectifs professionnels et académiques.
CV (cv.html) : Mon CV détaillant mon parcours académique et mes expériences professionnelles.
Contact (contact.html) : Formulaire permettant de m'envoyer un mail depuis une boîte mail.
Projets (projets.html) : Détails de mes projets réalisés, avec des images.
Expériences (experiences.html) : Section consacrée à mes expériences professionnelles et stages réalisés.
Veille technologique (veille.html) : Section où je partage mes recherches et découvertes récentes dans le domaine de la technologie notamment des cryptomonnaies

Technologies utilisées
-------
Le site utilise les technologies suivantes pour garantir une présentation moderne et fonctionnelle :

HTML5 : Structure et contenu des pages.
CSS3 : Mise en page et style, avec des variables CSS pour la gestion des couleurs.
JavaScript : Interaction dynamique avec l'utilisateur (formulaires, navigation fluide, etc.).
-------

Instructions pour tester le portfolio
-------
1. Dézippez l'archive du portfolio dans un dossier de votre choix.
2. Ouvrez le fichier index.html dans un navigateur web moderne (Chrome, Firefox, Edge, etc.).
3. Naviguez entre les pages en utilisant le menu de navigation ou les liens.
4. Testez les fonctionnalités interactives :
	- Formulaire de contact : Testez la validation du formulaire sur la page Contact.
	- Navigation fluide : Vérifiez la fluidité des transitions entre les différentes pages.
	- Alertes et messages : Vérifiez que le formulaire de contact vous notifie correctement si un champ est vide.
-------

Personnalisation du portfolio
-------
Style CSS : Le fichier style.css contient les styles principaux du portfolio. Les couleurs peuvent être modifiées grâce aux variables CSS définies dans :root.
Interactivité : Le fichier script.js contient le code JavaScript responsable de l'interactivité (ex. validation de formulaire, actions sur les boutons, etc.).
Images : Les images sont stockées dans le dossier images et sont référencées dans les pages HTML.
